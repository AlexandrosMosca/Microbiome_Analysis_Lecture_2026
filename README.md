# Microbiome_Analysis_Lecture_2026
This repository contains an R script for performing a standard plant microbiome analysis. The data are based on the high-throughput amplicon-based sequencing of a citrus microbiome survey conducted in our laboratory (https://www.mdpi.com/2073-4395/13/3/654, Dimaria et al., 2023), re-analyzed using the Amplicon Sequence Variant (ASV) method.
